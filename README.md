# Concurrent Network Port Scanner in Rust

یک ابزار اسکنر پورت شبکه هم‌روند (Concurrent) پیاده‌سازی شده با زبان Rust جهت ارزیابی وضعیت پورتهای TCP با سرعت بالا.

## ویژگی‌ها
- **اسکن هم‌روند (Multi-threading):** توزیع پردازش اسکن بین Threadهای مختلف جهت افزایش سرعت.
- **ارتباطات شبکه ایمن:** استفاده از `std::net::TcpStream` به همراه تنظیم مهلت زمانی (Timeout).
- **مدیریت خطای اصولی:** استفاده از ساختارهای `Result` و `Option` به جای دستورات ناامن.
- **ساختار ماژولار:** تفکیک منطق اسکن در `lib.rs` و ورود برنامه در `main.rs`.

## نحوه کامپایل و اجرا

برای اجرای برنامه از دستور زیر استفاده کنید:
